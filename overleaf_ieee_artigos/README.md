# Projetos IEEE para Overleaf

Cada subpasta e um projeto LaTeX independente. No Overleaf, envie os arquivos de uma unica subpasta e compile `main.tex` com `pdfLaTeX` e BibTeX.

Antes de submeter, substitua a autoria anonima e inclua resultados experimentais obtidos com uma base rotulada. Os manuscritos nao declaram metricas que ainda nao foram medidas.
